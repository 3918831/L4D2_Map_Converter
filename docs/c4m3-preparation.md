# C4M3 固定氛围预设：准备记录

日期：2026-09-13。起点：`v0.3.0` / `91d68d1`。本文件记录本机数据检查和下一阶段设计，**不是已实现或已实机通过的预设**。

## 范围

目标来源为 C4M3 `c4m3_sugarmill_b`，验证输入为原始 C2M1 `c2m1_highway`。沿用直接修改 BSP/LMP 实体、原生 HDR 光照重建、人工引擎反射采样及严格导入审计的流程。

候选预设 ID 为 `c4m3-overcast-static-v1`。名称强调固定阴沉氛围，当前不包含新增降雨区域、雨粒子、闪电、雷声、强风暴、屏幕震动或随机天气循环。基础暗光、天空、雾、色调、曝光及固定后处理属于此次目标，即使原实体名字中含有 `storm`，也不按名字直接丢弃其基础参数。

按此前约定，默认覆盖来源图的局部氛围参数；局部灯光和材质继续默认保留。建筑、模型布置、碰撞、NAV、路线、机关及尸潮事件保持。不会导入 C4 的关卡脚本、场景几何、积水布置、角色位置或音乐 Director 配置。C2 原开场镜头、控制器切换及淡入淡出需按作用分类，不为覆盖颜色而整条删除开场流程。

## 已核实的数据

测试安装和官方安装均找到 C4M3 基础 BSP，文件 SHA256 相同：

`8d482d83e6639fc4d024a89b4d4b988eeaa1ae44d1947221a07dd9d7a7172462`

测试安装中基础图有 1,086 个实体；h/l/s 模式补丁分别有 1,154 / 1,087 / 1,107 个实体。比较 world、光照、阴影、雾、调色、后处理、天空和色调控制器角色时，除位置、地图身份、Hammer ID 等非目标字段外，没有发现视觉参数差异。此结论不代表玩法实体或整份文件相同。

| 参数组 | 地图中的实际值或事实 | 固定预设的取值建议 |
|---|---|---|
| 天空 | `sky_l4d_c4m4_hdr` | 使用该实际资源名；不根据章节号拼接天空名 |
| 主调色 | `materials/correction/cc_c4_return.raw` | 用于 C2 主、开场、检查点等调色入口，保留必要切换时序 |
| 环境直射 | `_light = 200 225 230 10`；angles `0 315 0`；pitch `-15` | 保存颜色、强度、方向及原 HDR 回退字段 |
| 环境漫射 | `_ambient = 79 108 104 5` | 重烘焙世界与静态模型光照，不仅改运行时颜色 |
| directional light | `_light = 79 108 104 30`；angles `0 315 0`；pitch `-80` | 单独保存，不与环境直射方向合并 |
| 阴影控制 | color `0 0 0`；angles `80 315 0`；distance `70` | 与上述光照共同迁移；“无太阳实体”不代表没有光照方向或阴影 |
| 基础雾 | color `20 25 25`；start `0`；end `1500`；density `1`；farz `2000` | 采用初始化基础值，覆盖来源局部分区的对应字段 |
| 默认雾控制器 | `fog_storm` 的默认标志为 1；master/interior 为 0 | 按实际角色取值，不能一律用 `fog_master` 代表默认效果 |
| 天空雾 | start `0`；end `1`；color `20 25 25`；启用天空裁剪相关字段 | 单独记录与验证；保留 C2 天空几何，不能把世界雾距离直接当作天空雾距离 |

| 曝光启动值 | 三种角色 max `10`、min `1`；global rate `.25` | 使用固定启动状态，采样 guard 同步期待 max 10 |
| bright-pixels | 未发现 C5 那种启动设置输出 | 表达为“目标未显式设置”，不能自动补入 C5 的 5；确认 C2 原始输入未带自定义值 |
| 太阳实体 | 基础及三个模式均无 `env_sun` | 预设显式表达无太阳光斑；不沿用 C5 的新增太阳步骤 |
| 普通风 | `wind_normal`：15–30、gust 50–100，方向 `0 -180 0` | 纳入普通风配置；排除 `wind_storm` 的 75–150、gust 100–200 |

已核实天空六面 VMT 与主调色 RAW 共七项资源存在。后续正式构建仍需核对资源内容、材质依赖、模型资源、安装优先级及每次运行的哈希；本轮资源存在性不替代完整构建检查。

## 固定状态与动态天气的分界

建议第一版使用**初始化时的基础阴天状态**。这使参数可直接追溯，避免任选某次风暴周期的中间画面。另一个可行方向是固定“风暴峰值”的浓雾和更强后处理，但那是另一组目标参数，当前不混入此预设。

已观察到的动态变化包括：闪电时曝光升到 50，随后 global max 被写回 5；风暴进入时雾 start/end 改成 -512/768，farz 改成 1024；后处理 localcontrast 在 -.25 与 -.6 之间变化。风暴退去后的 end 1200 也不等于地图初始 end 1500。因此“从 C4M3 提取”必须明确提取哪个状态，不能用最后一条 I/O 覆盖初始值。

本机还发现 `director_c4_storm.nuc` 和对应 BeginScript 调用。本轮不解释加密脚本，也不将其导入 C2。C4 全部运行时状态尚未采样；以上固定状态是可复现的地图参数定义，不声称等同于原关卡任意时间点的画面。

## 声音与来源适配

C4M3 基础图有 12 种 soundscape 名称，包含雨、雷、冰雹和动态风暴引用。例如 `sugarmill.b.exterior` 包含 `distant.thunder`、`rain.hardsurface.hard`、`storm.dynamic`。因此不能把这些名字原样塞入“无雨雷”预设。

后续需分析嵌套 soundscape 的可复用非天气部分，形成独立命名的目标环境音定义，并追踪全部资源引用。某个室外定义剔除天气后若没有剩余内容，明确记录为空，不用 C5 海鸥声或另一个章节的声音冒充 C4 提取结果。工业火焰等局部场景音也需与使用场景区分，不能铺满 C2。

C2 基础图有 88 个 env_soundscape、六种来源名称，可保留空间覆盖并替换目标定义；三种模式分别审计。它的九个 ambient_generic 是车辆警报或发电机等事件声音，保持原行为。两个 env_wind 中有一组参数与 C4 wind_normal 相同，仍需检查两者实际作用及 skybox 关系，避免任意删除或重复新增全局风。

## 当前工程需要扩展的位置

1. **预设加载和 schema**：登记第二个目标；允许无太阳、缺少 intro 角色、缺少 bright-pixels，以及默认后处理与普通 exterior 不同。C4 采用明确的新数据结构或版本，保持 C5 v1 JSON 内容及哈希不变。
2. **来源与目标分离**：现有配置虽已有 `source_profile/preset`，内部 MAPS/dispatch、报错和 addon 描述仍带 C5 假设。改成显式兼容表，首批新增组合只开放 C2M1→C4M3，不自动宣称 C6→C4 已支持。
3. **C2 覆盖能力**：现有 C5 路径未覆盖全部 C2 后处理、检查点调色和环境音。为新预设补齐这些范围，检查缺失字段的插入、已存在字段替换、重复实体和未知氛围写入者；保护无关 I/O。C5 历史路径继续保持字节结果。
4. **曝光与幂等性**：当前 C2 输入检查只接受 max 6/5，新增目标 10 后需同时接受原始值和当前预设已应用值，不能第二次应用就失败。明确处理未显式设置的曝光项，guard 读取本次预设，不硬编码 C5 值。
5. **依赖和打包**：移除 C5 专属资源列表对新目标的约束；保留严格校验。将 C4 JSON 及必要的自有声音定义生成逻辑加入源码包、wheel、sdist 的显式清单，不分发 Valve 声音、贴图或地图。
6. **运行可追溯性**：延续预设快照、输入/资源哈希和人工采样交接；为 C2→C4 使用全新配置与输出目录，默认输入为原始 C2，不叠加在已转换 C5 的产物上。

## 下一阶段工作顺序与验收

1. 固化角色映射、初始状态选择和非天气声音策略；为新预设保存提取来源与参数清单。
2. 补失败测试：缺太阳、缺 bright-pixels、max 10、局部覆盖、未知写入者拒绝、C5 兼容、发行包资源。
3. 实现最小扩展；对原始 C2 基础及 h/l/s 应用新预设，核对参数、玩法保护、非实体 lump 和幂等性。
4. 回归 C2/C6→C5 的八组已保存结果逐字节相同，确认已有稳定成果未受影响。
5. 完成 C2→C4 离线 HDR 烘焙和七文件打包审计。重点看方向光、暗区层次、静态模型缓存以及无太阳光斑。
6. 再生成本次运行的完整人工采样指令；用户在游戏内采样 HDR cubemap，导入并校验最终包。
7. 用户按既定标准确认无异常、无劣化及氛围方向；参数报告验证覆盖是否完整。重点观察开场后、室内外、远景雾、车辆和武器反光；不以主观感受代替数据审计。

本轮已完成输入发现、参数与模式对照、静态/动态差异分析、目标资源存在检查和工程差距整理。没有生成可加载的 C4 预设、烘焙新地图、安装采样文件或启动游戏。

本机原始检查结果保存在忽略目录 `artifacts/c4m3-preparation/`，其中完整路径、实体摘录和游戏 soundscape 脚本仅作本地研究证据，不纳入公开源码。
